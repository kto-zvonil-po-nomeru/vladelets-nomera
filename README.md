## Начните с точной записи

Сохраните полный номер и проверьте несколько вариантов написания: с кодом страны, с начальной восьмёркой, с пробелами и без них. Поисковые системы могут по-разному распознавать разделители. Откройте найденные страницы, а не полагайтесь на короткий фрагмент выдачи. Упоминание может находиться в старой копии объявления, а имя рядом — принадлежать автору комментария. Запишите дату и тип источника: официальный сайт, пользовательская публикация или перепечатка. Чем ближе номер к прямому контакту на официальной странице, тем понятнее связь.
